# Engagement360 Methodology

## Strategic
- SWOT / selective PESTLE for context
- Fishbone + 5 Whys for root cause
- CRISP-DM for the data science lifecycle
- ADKAR for change enablement
- Power/Interest + RACI for stakeholders

## Analytics maturity
Descriptive → Diagnostic → Predictive → Prescriptive

## Governance
- human-in-the-loop decisioning
- explainability
- privacy and role-based access
- model/version auditability
- data quality monitoring

## Financial metric
Contract Exposure = monthly contract value × remaining months

Risk-Adjusted Revenue Exposure = Contract Exposure × model risk probability

This is an expected exposure estimate, not a claim of guaranteed financial loss.
